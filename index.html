Super Nintendo Web Player

Rode seus jogos de SNES direto pelo GitHub Pages usando EmulatorJS.

Como Jogar:
  • Clique no botão de ligar/carregar no centro da tela do emulador.
  • Use o ícone de pasta dentro do emulador para carregar seu arquivo de ROM (.sfc ou .smc).
  • Configure as teclas ou conecte um controle usb clicando no ícone de engrenagem.
